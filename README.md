### Himmel
This is a turn-based game with server written in Rust and frontend in NextJS.

> Currently there is no way to store the score etc.. I might have to use a database in future for authentication and character collections.

Backend&#39;s (Rust part aka &#39;/logic&#39;) heavy part is done, but the frontend is different story. The idea for frontend is - I want to use anime sprites to show the movements of the different characters having different moves.

I can&#39;t make sprites myself so I have to surf internet and find out packs that have similar characters, because many sprites will have different sizes and stuff, which will be a real headache to work with.

> If you want to run it right now
Clone the project and run the following commands
    cargo run
    yarn dev
